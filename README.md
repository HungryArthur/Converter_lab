# ЛР-1. Конвертер систем счисления

Решение на C11: основное задание, уровни A и B, дополнительный режим C.
Результат оценки зависит также от защиты: разберите алгоритмы по REPORT.md.

## Быстрый запуск в Windows

Дважды нажмите `run.bat`. Уже собранный `converter.exe` находится рядом.
Если запускаете из PowerShell, используйте `./converter.exe`.

Выберите пункт меню:

1. `dec -> base` - десятичное число в основание 2-16.
2. `base -> dec` - число из выбранного основания в десятичное.
3. `exit` - завершение программы.

Пример: пункт `1`, число `472`, основание `16` дают `result: 1D8`.
Дробную часть отделяет точка: `12.625`, а не запятая.
Для пересборки с установленным GCC запустите `build.bat`.

## Командная строка

```powershell
./converter.exe 472 16
# 1D8
./converter.exe 1D8 16
# 472
./converter.exe 12.625 2
# 1100.101
./converter.exe -table 255
./converter.exe -step 472 2
```

Направление определяется по первому аргументу, как в задании. Запись только
из десятичных цифр считается десятичным числом. Поэтому `101 2` переводит
десятичное 101 в двоичное; для перевода двоичного `101` в десятичное выберите
пункт 2 в меню. Переполнение десятичного аргумента считается ошибкой.

## Сборка и проверка в Linux / WSL

Нужны GCC и Make. Для дополнительных проверок нужны Cppcheck и Valgrind.

```sh
make all
./converter
sh tests.sh
python3 tests_properties.py ./converter
make check
valgrind --leak-check=full --show-leak-kinds=all --error-exitcode=1 ./converter < tests/dialog_examples.in
make clean
make re
# Все проверки Linux с сохранением логов:
sh verify_linux.sh
```

`tests.sh` содержит 45 сценариев и сравнивает stdout, stderr и код завершения
с файлами ожиданий. `tests_properties.py` дополнительно проверяет 3240
целочисленных преобразований, 180 дробных и 45 переполнений.
Python нужен только для дополнительного тестирования.

В MSYS2 можно выполнить `make` и `sh tests.sh` в терминале UCRT64.
На Windows программа печатает английские сообщения из примера задания,
чтобы результат не зависел от кодировки консоли.

преподавателю следует передать прежде всего исходники.

# Описание тестов

`sh tests.sh` сравнивает результат, поток ошибок и код завершения с
файлами `tests/*.out` и `tests/*.err`. Для диалога вход читается из
`tests/*.in` и передаётся программе через pipe; после ошибки проверяется
возврат к меню. Успех в CLI означает код 0, ошибка аргументов - код 1.

Всего 45 сценариев. В тесте нуля проверяется именно непустая строка `0`.

`tests_properties.py` использует генератор со стабильным seed и встроенный
Python `int` для независимой проверки результата в основаниях 2-16.
Проверяются 108 целых значений, включая обе границы `int`, ноль, отрицательные
и случайные числа: 1620 переводов туда и 1620 обратно со строчными буквами.
Дроби проверяются через `fractions.Fraction`: значение не увеличивается
по модулю при усечении, ошибка меньше единицы последнего разряда,
а предупреждение появляется именно при потере точности. Это 150 переводов
дробей туда и 30 обратно; ещё 45 запусков проверяют переполнение в CLI.
